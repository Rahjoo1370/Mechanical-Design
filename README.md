# سیستم مدیریت ارتباط با مشتری (CRM)

یک سیستم CRM کوچیک و کارآمد برای مدیریت مشتریان، گزارش‌های کار و پیگیری‌ها با قابلیت یادآوری خودکار.

## ویژگی‌های اصلی

### 📊 داشبورد
- نمایش آمار کلی سیستم (تعداد مشتریان، گزارش‌ها، پیگیری‌ها)
- نمایش پیگیری‌های امروز
- رنگ‌بندی پیگیری‌های عقب‌افتاده
- دکمه بررسی دستی یادآوری‌ها

### 👥 مدیریت مشتریان
- افزودن مشتری جدید با اطلاعات کامل
- ویرایش اطلاعات مشتریان موجود
- حذف مشتری (همراه با تمام اطلاعات مرتبط)
- جستجوی سریع در لیست مشتریان
- دابل کلیک برای انتقال سریع به گزارش‌های مشتری

### 📝 گزارش‌های کار
- ثبت گزارش کار برای هر مشتری
- انتخاب تاریخ گزارش با تقویم
- تعیین وضعیت گزارش (در انتظار، در حال انجام، تکمیل شده، لغو شده)
- فیلتر گزارش‌ها بر اساس مشتری
- ویرایش و حذف گزارش‌های موجود

### ⏰ سیستم پیگیری
- تعیین تاریخ پیگیری برای هر مشتری
- دکمه‌های سریع برای انتخاب تاریخ (امروز، فردا، هفته آینده)
- نمایش پیگیری‌های عقب‌افتاده با رنگ قرمز
- تکمیل کردن پیگیری‌ها
- فیلتر نمایش پیگیری‌های تکمیل شده

### 🔔 سیستم آلارم و یادآوری
- بررسی خودکار پیگیری‌ها هر 30 دقیقه
- نمایش پاپ‌آپ یادآوری برای پیگیری‌های امروز و عقب‌افتاده
- پخش صدای سیستم هنگام یادآوری
- امکان بررسی دستی یادآوری‌ها

## نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.7 یا بالاتر
- سیستم عامل Windows (برای قابلیت صدای یادآوری)

### نصب
1. فایل‌های پروژه را دانلود کنید
2. کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
```

### اجرا
```bash
python main.py
```

## ساختار فایل‌ها

```
├── main.py              # فایل اصلی برنامه
├── main_methods.py      # متدهای اضافی CRM
├── database.py          # مدیریت پایگاه داده SQLite
├── dialogs.py          # فرم‌های ورودی (مشتری، گزارش، پیگیری)
├── requirements.txt     # کتابخانه‌های مورد نیاز
├── README.md           # راهنمای استفاده
└── crm_database.db     # فایل پایگاه داده (ایجاد خودکار)
```

## نحوه استفاده

### افزودن مشتری جدید
1. به تب "مشتریان" بروید
2. روی "مشتری جدید" کلیک کنید
3. اطلاعات مشتری را وارد کنید (نام الزامی است)
4. "ذخیره" را کلیک کنید

### ثبت گزارش کار
1. به تب "گزارش‌های کار" بروید
2. روی "گزارش جدید" کلیک کنید
3. مشتری مورد نظر را انتخاب کنید
4. تاریخ، عنوان و توضیحات را وارد کنید
5. وضعیت گزارش را تعیین کنید
6. "ذخیره" را کلیک کنید

### تعیین پیگیری
1. به تب "پیگیری‌ها" بروید
2. روی "پیگیری جدید" کلیک کنید
3. مشتری و تاریخ پیگیری را انتخاب کنید
4. عنوان و توضیحات را وارد کنید
5. "ذخیره" را کلیک کنید

### مشاهده آمار
1. به تب "داشبورد" بروید
2. آمار کلی در بالای صفحه نمایش داده می‌شود
3. پیگیری‌های امروز در جدول زیر قابل مشاهده است

## قابلیت‌های پیشرفته

### جستجوی سریع
- در تب مشتریان، با تایپ در کادر جستجو، لیست به‌روزرسانی می‌شود

### فیلتر گزارش‌ها
- در تب گزارش‌ها، می‌توانید گزارش‌های یک مشتری خاص را مشاهده کنید

### رنگ‌بندی پیگیری‌ها
- پیگیری‌های عقب‌افتاده با پس‌زمینه قرمز نمایش داده می‌شوند

### یادآوری خودکار
- سیستم هر 30 دقیقه پیگیری‌ها را بررسی می‌کند
- در صورت وجود پیگیری فوری، پاپ‌آپ یادآوری نمایش داده می‌شود

## پشتیبانی از زبان فارسی
- تمام رابط کاربری به زبان فارسی است
- پشتیبانی کامل از متن راست به چپ
- قابلیت ورود اطلاعات به فارسی

## امنیت داده‌ها
- تمام اطلاعات در پایگاه داده محلی SQLite ذخیره می‌شود
- هیچ اطلاعاتی به اینترنت ارسال نمی‌شود
- پشتیبان‌گیری از فایل `crm_database.db` توصیه می‌شود
